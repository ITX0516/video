# ShortFeed 真机回归清单

每一版 APK 装机后按此清单过一遍。**任何一项不符合预期都算回归，先别继续用新版本。**

记录方式：通过打 `✓`，失败写实际现象。加载类失败请附「诊断」页复制内容。

环境信息（每次填写）：机型 / Android 版本 / 网络（WiFi 或流量）/ 是否已登录 B站 / 是否已登录抖音。

---

## 1. 启动与内容源

- [ ] 冷启动进入主界面，无闪退、无白屏。
- [ ] 只勾 Bilibili → 进入沉浸模式，能刷出推荐视频。
- [ ] 只勾抖音（未登录）→ 有内容或明确的失败提示，不是永久黑屏。
- [ ] 播放中按音量键 → 切换到下一个已启用内容源，当前源视频停止发声。
- [ ] 切回上一个源 → 能正常加载，不卡在空列表。

## 2. 播放与手势

- [ ] 上滑 / 下滑切换视频，动画顺畅，无残影。
- [ ] 当前视频自动播放且有声音；滑走后上一条静音。
- [ ] 单击屏幕 → 出现控制条；点「隐藏全部 UI」→ 画面完全干净（无信息卡片）。
- [ ] 返回键：控制条可见时先收控制条，再按一次退出到主界面。
- [ ] 双指捏合放大 → 画面放大且不溢出到相邻页；双指拖动平移；「重置」恢复 100%。
- [ ] 单指竖滑翻页不受双指缩放功能影响。

## 3. 加载反馈与重试

- [ ] 弱网（或开飞行模式后恢复）时，黑屏上有「加载中…」转圈，不是无声黑屏。
- [ ] 加载失败时显示错误码与「重试」按钮。
- [ ] 点「重试」后能重新加载成功（网络正常时）。
- [ ] 失败后直接滑到下一条，下一条不受影响。

## 4. 清晰度

### Bilibili
- [ ] 控制条有「清晰度 360P / 480P / 720P / 1080P」。
- [ ] 切换后当前视频重载，新档位生效，声音正常。
- [ ] 滑到下一条仍使用所选档位。
- [ ] 未登录时选 1080P 不会卡死（可能实际只给到更低档）。

### 抖音
- [ ] 有多档的视频出现「自动 / 最低 / 各档位」，档位过多时该行可左右滑动。
- [ ] 选「最低」后每条都用其最低档播放；若该档直链返回 403，自动回退到 feed 主地址，不显示「视频加载失败」。
- [ ] 选 540P 后刷到只有 720P 的视频 → 自动降级播放，**不卡住**。
- [ ] 切换清晰度后当前视频立即重载。

## 5. 播放器池与缓存

- [ ] 往下刷 5 条再往回刷 → 立即出画面，不转圈，进度延续。
- [ ] 往回刷超过 7 条 → 该条重新加载（预期行为）。
- [ ] 看过一遍的视频，断网后往回刷 → 已缓存部分仍可播放（磁盘缓存生效）。
- [ ] 连续刷 50 条无闪退、无明显发热；低配机特别留意内存。

## 6. 本地赞 / 收藏

- [ ] 沉浸模式点「♥ 赞」「★ 收藏」有浮动提示。
- [ ] 主界面「我的赞 / 收藏」两个 tab 都有对应记录，标题与作者正确。
- [ ] 点开一条 → 显示「正在重新解析播放地址…」→ 全屏播放。
- [ ] **收藏超过半天的 B站条目仍能播放**（重新解析生效，而非用过期直链）。
- [ ] 再次点赞/收藏同一条 → 记录被取消，列表刷新后消失。

## 7. 视频信息浮层

- [ ] 控制条点「信息」→ 左下角显示标题 / 作者·平台 / id。
- [ ] 滑到下一条信息跟着变。
- [ ] 再点「隐藏信息」或「隐藏全部 UI」→ 浮层消失。

## 8. 登录

- [ ] 「Bilibili 登录」扫码/账号登录成功后，推荐流变为账号个性化内容。
- [ ] 退出登录或 cookie 失效后，表现为可解释的加载失败，而不是无限黑屏。
- [ ] 「抖音网页版」登录后，沉浸模式能取到推荐流。
- [ ] 已登录且有关注时，点「关注」能立即出内容；不再因切页后清空缓冲而永久空白。

## 9. 诊断

- [ ] 制造一次失败（如飞行模式下进沉浸模式）→ 主界面「诊断」有对应记录（平台、id、错误码）。
- [ ] 「复制全部」能把文本贴到微信/备忘录。
- [ ] 「清空」后列表为空。

## 10. 安装与升级

- [ ] 覆盖安装上一版不丢收藏、不丢清晰度设置。
- [ ] 卸载重装后应用可正常启动（收藏清空属预期）。
